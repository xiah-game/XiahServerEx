# XiahServerEx (新侠道 - 服务端)

## 项目简介
XiahServerEx 是《新侠道》(Xiah) 的核心游戏服务端项目。它负责处理所有与玩家相关的业务逻辑，如角色登录鉴权、地图场景管理、怪物 AI 运算、战斗伤害判定、物品掉落计算、技能释放验证以及与数据库的持续交互。该端作为整个网络游戏的权威逻辑中心，确保各个客户端之间的数据同步与防作弊。

## 有啥用 (核心功能)
- **账号与会话**: 负责账号注册、密码校验及底层登录会话管理 (AuthServer)。
- **场景与同步**: 处理区域地图内的 AOI (感兴趣区域) 广播、玩家坐标移动同步、组队(DAN)系统以及广播聊天功能。
- **战斗引擎**: 包含复杂的怪物状态机驱动 AI 以及严谨的攻防、暴击、技能 IP/TP 消耗结算系统。
- **持久化存储**: 通过 ODBC / SQL 实时落地玩家的等级、经验、背包物品和属性数据，防止回档。

## 编译依赖
- **操作系统**: Windows
- **开发工具**: Visual Studio (推荐 VS 2019 / 2022，带 C++ 桌面开发组件)。
- **构建系统**: CMake (项目支持通过 CMake 生成解决方案) 或直接使用目录下的工程文件。
- **数据库**: SQL Server (需在系统 ODBC 数据源中配置正确的 DSN)。

## 如何编译
1. **使用 Visual Studio**：若已安装 CMake，可直接在 VS 中以“CMake 文件夹”方式打开根目录；或双击打开项目根目录下的 `.sln` 解决方案文件。
2. **配置选择**：推荐选择 `RelWithDebInfo`（带调试信息的发布版）或 `Debug` 进行构建。
3. **生成**：在 IDE 中右键点击解决方案并选择 **生成 (Build)**。
4. **准备运行**：编译成功后，进入输出目录。运行前务必确保根目录下的 `config.ini` 文件中的数据库连接字符串、监听端口配置正确。
5. **启动**：直接运行生成的 `.exe` 可执行文件即可启动服务。
